Крок 1 · Порівняння

Правда чи ні?

Python уміє порівнювати значення. Відповідь завжди одна з двох: True (правда) або False (неправда) — це тип bool.

>більше
<менше
>=більше або дорівнює
<=менше або дорівнює
==дорівнює
!=не дорівнює
Один знак = кладе значення в змінну, а два == — порівнюють. Їх часто плутають.

Крок 2 · Команда if

Якщо умова правдива — виконуй

Команда if («якщо») перевіряє умову. Рядки під нею виконуються, лише коли умова — True.

if age >= 10:
    print("Можна на гірку")
  • після умови — двокрапка :;
  • рядки всередині if мають відступ — 4 пробіли (клавіша Tab).

Програму з if можна уявити як дорогу з розвилкою. На розвилці Python перевіряє умову й обирає шлях: True — через рядок з відступом, False — в обхід нього. Далі обидва шляхи сходяться.

Крок 3 · Інакше: else

Два шляхи

Слово else («інакше») додає другий шлях: його рядки виконуються, коли умова — False. Умову після else не пишуть.

if password == "python":
    print("Вхід дозволено")
else:
    print("Неправильний пароль")

Крок 5 · Кілька шляхів: elif

Що вдягнути?

Коли шляхів більше двох, між if і else ставлять elif («інакше, якщо»). Python перевіряє умови згори вниз і виконує лише першу правдиву.

Коли одна умова спрацювала, решту Python навіть не перевіряє — пересунь повзунок і подивись на підписи.

Крок 6 · and, or, not

Складні умови

Кілька умов можна поєднати в одну:

  • and («і») — правда, коли правдиві обидві умови;
  • or («або») — правда, коли правдива хоча б одна;
  • not («не») — перевертає: True стає False, і навпаки.
if age >= 7 and height >= 120:
    print("Можна на американські гірки")

Обери умову словами, а потім клацни її запис у Python.

Який у тебе рівень?

  • 4–6 — середній;
