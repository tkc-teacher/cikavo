Поки умова правдива: цикл while

Навчишся повторювати команди й вчасно зупиняти повторення.

Повторення · Заняття 4–5

Розминка

Згадаймо умови й випадкові числа — без них циклів не буде.

Крок 1 · Навіщо цикли

Повторюй, поки…

Цикл повторює команди. while означає «поки»: повторюй, поки умова правдива.

Обери дію, а потім — умову до неї.

Крок 2 · Команда while

Як крутиться цикл

n = 1
while n <= 3:
    print(n)
    n = n + 1
print("Готово!")
  • після умови — двокрапка :;
  • рядки з відступом — тіло циклу;
  • один прохід тіла — ітерація.

Після кожної ітерації Python знову перевіряє умову. Стала False — цикл закінчено.

Межа:
Обери межу й запусти програму.

Консоль
З межею 0 тіло циклу не виконається жодного разу.
Крок 3 · Лічильник

Скільки разів?

Змінна, що рахує ітерації, — лічильник. Кількість ітерацій залежить від:

  • початкового значення;
  • кроку;
  • умови — особливо < чи <=.

Скільки разів виконається print()?

Крок 5 · Нескінченний цикл

Коли цикл не зупиняється

Якщо умова ніколи не стає False, цикл крутиться вічно — це нескінченний цикл. Причини:

  • лічильник не змінюється;
  • змінюється не в той бік;
  • рядок зі зміною — без відступу;
  • лічильник «перестрибує» число в умові з !=.
Тут програму зупиняє сама сторінка через 8 с. У редакторі — клавіші Ctrl+C.

Клацни рядок, через який цикл не закінчиться.

Запусти нескінченний цикл, а тоді допиши рядок, щоб «Привіт!» вивелось 5 разів.

Крок 6 · while True і break

Вийти з циклу будь-коли

while True: крутиться завжди, а break негайно виходить з циклу. Рядки після break у тілі вже не виконуються.

while True:
    answer = input("Скільки буде 2 + 2? ")
    if answer == "4":
        break
    print("Ні, спробуй ще")
print("Правильно!")
Зручно, коли невідомо, скільки буде спроб.
