Крок 1 · Перша програма

Комп'ютер виконує команди дослівно

Програма — це набір команд, які комп'ютер виконує по черзі й дослівно. Записують їх мовою програмування, наприклад Python.

Код пишуть у редакторі, запускають кнопкою, а результат з'являється в консолі. На наших заняттях усе це вже вбудовано в сторінку.

Назва Python — не від змії, а від британського комедійного шоу «Monty Python».
Крок 2 · Команда print()

print() виводить на екран

Команда print() виводить у консоль те, що стоїть у дужках.

  • текст — у лапках: print("Привіт");
  • приклад — без лапок: print(2 + 3) виведе 5;
  • кожен print() — окремий рядок.

Крок 4 · Помилки

Помилятися — нормально

Python зупиняє програму й показує рядок з помилкою. Найчастіші помилки:

  • забута лапка чи дужка: print("Привіт);
  • велика літера: Print("Привіт");
  • текст без лапок: print(Привіт).
