💌 Листівки друзям

Напиши одну листівку в Блокноті, розмнож її копіюванням і розклади копії по папках на Робочому столі. А наприкінці перенеси все в Документи.

Покроково

1

Приготуй скриньку на Робочому столі

  1. Згорни всі вікна: Win + D.
  2. Правою кнопкою на порожньому місці Робочого столу → Створити → Папку.
  3. Напиши Листівки і натисни Enter.
  4. Двічі клацни папку Листівки — вона відкриється в Провіднику.

2

Напиши листівку

  1. У папці Листівки: правою кнопкою → Створити → Текстовий документ.
  2. Назви його Листівка → Enter.
  3. Двічі клацни його — відкриється Блокнот.
  4. Напиши побажання на 1–2 речення.
  5. Збережи: Ctrl + S. Закрий Блокнот.

3

Розмнож листівку

  1. Клацни Листівка один раз, щоб виділити.
  2. Ctrl + C — копія в буфері обміну.
  3. Ctrl + V — тричі.

4

Підпиши кожну копію

  1. Клацни копію → F2.
  2. Напиши Для та ім'я → Enter.
  3. Так само підпиши решту: двоє друзів і хтось із рідних.

5

Розклади по скриньках

  1. У папці Листівки створи ще дві папки: Друзям і Рідним.
  2. Перетягни кожну листівку мишею на потрібну папку.

6

Переїзд у Документи

  1. Закрий Провідник. На Робочому столі клацни папку Листівки → Ctrl + X.
  2. Відкрий Провідник (Win + E) → ліворуч Документи.
  3. Клацни на порожньому місці → Ctrl + V.
