Крок 2 · Копія чи переїзд

Копіювати чи переміщувати

Ці дві дії легко сплутати. Подивись, чим відрізняється результат.

Копіювати

Копіювати → Вставити
Файл є в обох місцях.

Переміщувати

Вирізати → Вставити
Файл лише в новому місці.
content_paste
Команди «Копіювати» і «Вирізати» кладуть файл у буфер обміну — невидиму «кишеньку» комп'ютера. Команда «Вставити» дістає його з кишеньки там, де ти зараз.

Як скопіювати файл на флешку? Обирай кроки по черзі.

    Крок 4 · Кошик

    Кошик: другий шанс для файлів

    Видалений з комп'ютера файл не зникає одразу — він потрапляє в Кошик. Звідти його можна повернути.

    Файли, видалені з флешки, у Кошик не потрапляють — вони зникають одразу.
    Shift + Delete видаляє файл назавжди, оминаючи Кошик.

    Крок 5 · Провідник

    Наведи лад у Провіднику

    Файли й папки у Windows показує програма Провідник. Виконай завдання будь-яким способом: кнопками на панелі, правим кліком, гарячими клавішами чи перетягуванням.

      Почни з першого завдання. Папки відкривай подвійним клацанням.
      Загубив файл? Клацни поле Пошук у Провіднику (значок лупи) і введи частину його назви — комп'ютер сам знайде, у якій він папці.
