Крок 2 · Виведення: print()

Три способи вивести текст і число

Змінна score = 70 — рахунок гравця. Ось як показати його зрозуміло:

Через кому

print("Рахунок:", score)

Пробіл між частинами print ставить сам.

Через +

print("Рахунок: " + str(score))

Склеює лише рядки. Пробіл — самому, число — через str().

f-рядок

print(f"Рахунок: {score}")

Літера f перед лапками, змінна — у фігурних дужках.

Склеюючи рядки через +, не забудь пробіл: "100 метрів" + "спринт" дасть 100 метрівспринт.

Крок 3 · Введення: input()

Розпитуємо користувача

У дужках input() пишуть підказку — що саме ввести. Програма чекає, доки користувач надрукує відповідь і натисне Enter.

  • текст: name = input("Як тебе звати? ")
  • ціле число: age = int(input("Вік: "))
  • дійсне число: height = float(input("Зріст, м: "))
Пробіл у кінці підказки — щоб відповідь не прилипала до запитання.

Крок 5 · Порядок дій

Що Python рахує першим

Порядок дій — як у математиці й у формулах Google Таблиць:

  1. дужки ( );
  2. степінь **;
  3. множення й ділення: * / // % — зліва направо;
  4. додавання й віднімання: + - — зліва направо.

Клацай оператори в тому порядку, у якому Python їх виконає.

Крок 6 · Оператори присвоювання

Коротший запис: += і подібні

Щоб змінити значення змінної, її можна записати двічі: score = score + 10.
Коротше — score += 10.

x += 5 — те саме, що x = x + 5
x -= 5 — те саме, що x = x - 5
x *= 2 — те саме, що x = x * 2
x //= 2 — те саме, що x = x // 2

Гравець проходить рівень. Виконуй програму рядок за рядком і стеж за рахунком.

Крок 7 · Модуль math

Готові математичні функції

Деякі функції є в Python одразу, а інші лежать у модулі math.
Його підключають на початку програми: import math.

math.sqrt(16) → 4.0 — квадратний корінь
abs(-8) → 8 — модуль числа
math.ceil(4.1) → 5 — округлити вгору
round(3.14159, 2) → 3.14 — округлити до 2 цифр
math.floor(4.9) → 4 — округлити вниз
max(4, 9, 2), min(…) → найбільше, найменше

Крок 8 · Коментарі

Нотатки для людей

Коментар — пояснення після знака #, яке Python пропускає.

import math
r = 10    # радіус кола, см
# площа кола: π · r²
print(math.pi * r ** 2)

Довгий пояснювальний текст на кілька рядків беруть у потрійні лапки """…""".
