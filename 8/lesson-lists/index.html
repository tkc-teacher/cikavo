Змінні та команди. Працюємо зі списками

Крок 1 · Що таке список

Багато значень в одній змінній

У звичайній змінній — одне значення. А якщо треба зберегти всіх своїх улюбленців чи всі оцінки за місяць? Для цього є список.

  • Список (list) — упорядкований набір значень, збережений в одній змінній.
  • Елемент — одне значення в списку.
Змінна — одне значення.
Список — багато значень у порядку, як вагончики потяга.

Список записують у квадратних дужках, елементи — через кому:

pets = ["кіт", "пес", "хом'як", "папуга", "рибка"]
marks = [10, 8, 11, 9]
empty = []                    # порожній список
mix = [14, "Оля", 1.65, True]  # можна змішувати типи

Крок 2 · Індекси

Кожен елемент має номер

Номер елемента в списку називають індексом. Щоб дістати елемент, індекс пишуть у квадратних дужках після назви списку: pets[1].

  • нумерація починається з нуля: перший елемент — pets[0];
  • від'ємні індекси рахують з кінця: pets[-1] — останній елемент;
  • індексу, якого немає, брати не можна: pets[5] — помилка IndexError.
Крок 3 · Змінюємо список

Замінити, додати, видалити

Список можна змінювати після створення. Більшість команд пишуть через крапку після назви списку:

  • songs[0] = "Зірка"замінити елемент з індексом 0
  • songs.append("Дощ")додати елемент у кінець списку
  • songs.remove("Сонце")видалити елемент за значенням (перший такий)
  • del songs[2]видалити елемент за індексом

Виконуй програму рядок за рядком і стеж за списком у пам'яті.

Крок 4 · Функції для списків

Скільки, сума, найбільше

Python уміє швидко порахувати щось про весь список:

  • len(marks)кількість елементів
  • sum(marks)сума всіх елементів
  • max(marks), min(marks)найбільший і найменший елемент
  • marks.sort()упорядкувати за зростанням
sum(), max() і min() не працюють зі змішаним списком, де є і числа, і текст.

Список marks = [9, 12, 6, 10, 6]. Клацни команду, а потім — її результат.

Крок 5 · Зрізи

Беремо частину списку

Зріз — частина списку. Його записують двома індексами через двокрапку: week[2:5] — від індексу 2 до 5, але сам елемент з індексом 5 не входить.

  • week[:3] — від початку до індексу 3;
  • week[5:] — від індексу 5 до кінця.

Крок 7 · Google Colab

Python просто в браузері

Google Colab — безкоштовний онлайн-сервіс Google, у якому пишуть і запускають програми на Python. Нічого встановлювати не треба: потрібні лише браузер та обліковий запис Google.

  • Файл Colab називають блокнотом (notebook), розширення — .ipynb.
  • Блокнот складається з клітинок: у клітинках коду — програма, у текстових — нотатки.
  • Результат з'являється одразу під клітинкою.

З чого складається вікно

  • 1Назва блокнота — клацни, щоб змінити.
  • 2Меню: File — файл, Runtime — запуск програм.
  • 3+ Code — нова клітинка коду, + Text — текстова.
  • 4Запуск клітинки; число [1] — якою за порядком вона виконувалась.
  • 5Результат роботи клітинки.
  • 6Підключення до сервера Google: зелена галочка — усе готово.

Корисно знати

  • Shift + Enter — запустити клітинку й перейти до наступної; Ctrl + Enter — запустити й лишитися в ній.
  • Змінні з однієї клітинки видно в інших, але лише після того, як ту клітинку запустили.
  • Блокнот зберігається сам — на Google Диску, у папці Colab Notebooks.
Colab може бути англійською — тут назви кнопок такі, як на екрані. Він також пропонує дописати код за допомогою ШІ: спершу спробуй сам, інакше не навчишся.
