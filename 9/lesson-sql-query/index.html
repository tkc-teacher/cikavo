Крок 1 · Мова SQL

Чотири слова, які розуміє база

SQL (Structured Query Language) — мова структурованих запитів. Нею «розмовляють» майже всі бази даних:

Microsoft AccessMySQLPostgreSQLSQLite — у кожному смартфоні

Запит SQL читається майже як англійське речення. Ось запит до таблиці притулку «Тварини»:

Змінюй частини запиту в списках — і дивись, як змінюється вибірка.

SELECT ВИБЕРИ — які поля показати
FROM ТвариниЗ — з якої таблиці
WHERE ДЕ — умова відбору записів
ORDER BY ;ВПОРЯДКУЙ ЗА — сортування
→
Вибірка
  • ASC — сортування за зростанням (від А до Я, від меншого до більшого). Його можна не писати.
  • DESC — за спаданням (від Я до А, від більшого до меншого).
  • * після SELECT — показати всі поля.
  • AND і OR — знайомі І та АБО для кількох умов.
Текст в умові береться в одинарні лапки: 'Кіт'. Числа — без лапок: Вік > 5.

Крок 2 · Функція QUERY

SQL усередині Google Таблиць

У Google Таблицях є функція QUERY — вона виконує запит, схожий на SQL. Ось той самий запит:

=QUERY(Тварини!A1:F15; "SELECT B, D WHERE C = 'Кіт' ORDER BY D DESC")

Правила запису:

  • Перший аргумент — діапазон таблиці разом із рядком заголовків.
  • Другий аргумент — текст запиту в подвійних лапках "…".
  • Стовпці називають літерами: B, а не Кличка.
  • Текст в умові — в одинарних лапках: 'Кіт'.
  • Порядок частин сталий: SELECT → WHERE → ORDER BY.
Великі чи малі літери в словах запиту — неважливо: select теж спрацює. А на відміну від FILTER, QUERY сама додає рядок заголовків, вибирає потрібні стовпці й сортує — усе однією формулою.

Чи спрацює така формула?

Крок 3 · SELECT і WHERE

Які стовпці й які записи

SELECT обирає стовпці вибірки, а WHERE — записи (рядки). Без WHERE у вибірку потрапляють усі записи.

Обери стовпці, за потреби додай умову WHERE і натисни «Виконати». Вихідні дані — на аркуші «Тварини».

Крок 4 · ORDER BY

Сортуємо вибірку

ORDER BY сортує вибірку за стовпцем: текст — за абеткою, числа — від меншого до більшого. Слово DESC після стовпця перевертає порядок.

Можна сортувати за кількома стовпцями через кому: ORDER BY C, D DESC — спершу за видом, а всередині виду — від старших до молодших.

Обери стовпці, додай сортування ORDER BY (і умову WHERE, якщо треба) та натисни «Виконати».

Крок 5 · Запит повністю

Збери запит з плиток

Тепер — увесь запит самостійно: SELECT, потім за потреби WHERE, наприкінці ORDER BY. Кому між стовпцями формула поставить сама.

Клацай плитки по черзі — вони додаються в кінець запиту. Помилився — «⌫ Стерти».
