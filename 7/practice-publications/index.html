Кулінарна книга класу

Клас збирає свою кулінарну книгу. Зроби для неї сторінку з рецептом сирників у Google Документах. Потім збережи її для друку, для електронної книги й для подальшого редагування.

⏱ 25–30 хвGoogle Документи
📖Зверни увагу: рецепт — лінійний текст. Кроки читають і виконують лише по порядку, тому їх нумерують.

Що має вийти

Сирники

Сніданок за 20 хвилин

Інгредієнти

Сир кисломолочний — 400 г

Яйце — 1 шт.

Борошно — 3 ст. ложки

Цукор — 2 ст. ложки

Олія для смаження

Приготування

Розімни сир виделкою.

Додай яйце й цукор, перемішай.

Всип борошно й заміси тісто.

Зліпи невеликі кружечки й обваляй у борошні.

Обсмаж із двох боків до золотистого кольору разом із дорослими.

Рецепт додав(-ла): Ім'я Прізвище

Покроково

1

Створи документ

Обери один зі способів:

🎓 Через Google Classroom
  1. Відкрий завдання → Переглянути вказівки.
  2. У блоці «Ваша робота»: Додати або створити → Документи.
📁 Через Google Диск
  1. Створити → Google Документи → Порожній документ.
  2. Клацни «Документ без назви» і назви файл: Сирники.
2

Встав текст

  • Встав у документ: Ctrl + Shift + V. Так текст вставиться без чужого оформлення.
  • В останньому рядку заміни «Ім'я Прізвище» на своє.
Перевір себе: у документі 15 абзаців.
3

Оформи заголовки

  • Сирники: шрифт Lobster, розмір 36, по центру, помаранчевий колір.
  • Сніданок за 20 хвилин: курсив, по центру.
  • Інгредієнти і Приготування: напівжирні, розмір 14, синій колір.
  • Останній рядок: курсив, праворуч.
Lobster немає в списку? Шрифт → Інші шрифти → знайди Lobster → OK.
4

Списки

  1. Виділи п'ять інгредієнтів → format_list_bulleted Маркований список.
  2. Виділи п'ять кроків приготування → format_list_numbered Нумерований список.
Інгредієнти можна брати в будь-якому порядку, тому маркери. Кроки йдуть лише по черзі, тому номери.
5

Додай фото

  1. Постав курсор у кінець рядка «Сніданок за 20 хвилин» і натисни Enter.
  2. Вставлення → Зображення → Пошук в Інтернеті → введи сирники → обери фото → Вставити.
  3. Зменш фото за кутовий маркер і постав по центру.
Перевір себе: уся сторінка вміщається на одному аркуші.
6

Збережи для різних читачів

  1. Для друкованої книги: Файл → Завантажити → Документ PDF (.pdf).
  2. Для електронної книги: Файл → Завантажити → Публікація EPUB (.epub).
  3. Щоб інші могли редагувати у Word: Файл → Завантажити → Microsoft Word (.docx).
Перевір себе: у папці «Завантаження» три файли «Сирники» — .pdf, .epub і .docx.
7

Порівняй

  1. Відкрий Сирники.pdf і зміни розмір вікна. Сторінка лишається такою ж, як у документі.
  2. Завантаж ще й Звичайний текст (.txt) і відкрий його.
Перевір себе: у TXT лишився лише текст. Немає ні фото, ні шрифту Lobster, ні кольорів.
