## Вимоги до файлів

- PNG із прозорим тлом (картка світла — біле тло буде видно квадратом).
- Приблизно квадратні, 128–330 px; на сторінці показуються в 46 px.
- Назви файлів саме такі, як у таблиці, малими літерами.

Якщо файлу немає, картка автоматично підставляє емодзі — урок працює в будь-якому разі,
тож відсутні зображення можна додавати поступово.
